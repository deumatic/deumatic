# Deumatic Brand Assets

Save all AI-generated logo candidates in `logos/source-candidates`.

Use these folders after a logo is approved:

- `logos/final/horizontal` for the complete icon and wordmark
- `logos/final/icon` for the standalone symbol and favicon source
- `logos/final/monochrome` for black and white variants
- `social/linkedin` for the LinkedIn profile image and banner
- `web` for website-specific brand graphics

Preferred final formats are SVG for the website and PNG with transparency for social platforms and documents.

Approved colors:

- Carbon Ink: `#0B1420`
- Precision Blue: `#1F5CFF`
- Warm Alabaster: `#F5F2EA`
- Champagne Gold: `#D3B36A`
